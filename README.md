# ML Project 2026

Machine learning course project: regression (Part A), image classification (Part B), text classification (Part C), and a GUI.

## Structure
- `part_a_numerical/` - price prediction (regression)
- `part_b_images/` - image classification
- `part_c_text/` - text classification
- `gui/` - graphical user interface
- `models/` - saved trained models

## Setup
Install requirements with `pip install -r requirements.txt`.
(Instructions for running each notebook and the GUI will be added.)
